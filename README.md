# OrangeOS v1.0

> 一个基于 x86 架构，从 BootLoader 开始自主实现的教学型操作系统\
> Inspired by 《Orange'S：一个操作系统的实现》

------------------------------------------------------------------------

# 1. 项目简介

OrangeOS 是一个从零实现的小型操作系统项目。

项目目标：

-   理解计算机启动流程
-   掌握 BootLoader、Kernel、Interrupt、Process 等操作系统核心机制
-   实现一个具有 Shell、文件系统、多任务能力的微型 OS
-   在基础 OS 功能之上扩展具有展示性的特色模块

最终系统目标：

    BIOS
     |
    Boot Sector
     |
    Boot Loader
     |
    Kernel
     |
    User Interface

------------------------------------------------------------------------

# 2. 功能规划

项目功能分为：

-   核心系统模块（必须完成）
-   系统功能模块（重点完成）
-   创新扩展模块（根据进度完成）

# 3. 核心系统模块

## 3.1 BootLoader 模块

目标：

实现：

    BIOS
     ↓
    Boot Sector
     ↓
    Loader
     ↓
    Kernel

主要功能：

-   BIOS启动
-   Boot Sector加载
-   Loader加载Kernel
-   初始化运行环境
-   跳转Kernel入口

启动效果：

    ====================
         OrangeOS
    ====================

    Loading Kernel...

------------------------------------------------------------------------

## 3.2 Kernel 内核模块

负责：

-   系统初始化
-   硬件资源管理
-   提供系统服务

结构：

    ├── main.c
    └── kernel.asm

启动：

    OrangeOS Kernel Started

# 9. 开发原则

1.  每个模块必须可运行验证

2.  每个阶段提交 Git：

例如：

    Day1: boot sector works

    Day5: boot loader completed

    Day10: protected mode enabled

3.  优先保证系统稳定，再扩展特色功能

------------------------------------------------------------------------

# 10. 项目目标

最终 OrangeOS 希望达到：

-   能独立启动
-   拥有自己的 Kernel
-   支持多任务
-   支持文件管理
-   拥有交互 Shell
-   提供系统监控与可视化展示

成为一个具有完整结构和展示价值的小型操作系统。
