# OrangeOS Day22 开发日志

## 今日目标

实现用户进程页资源的按需分配、解除映射和物理页回收。

## 完成内容

### 1. 动态用户页生命周期

启动阶段不再永久保留用户代码、数据和栈页。执行 `user`、`run` 或 `runfault` 时：

1. 分配用户代码页；
2. 分配用户数据页；
3. 分配用户栈页；
4. 建立带 U/S 权限的 PTE；
5. 复制用户程序并清空数据页。

以下路径都会解除三个 PTE、执行 `INVLPG` 并归还物理页：

- 正常 `SYS_EXIT`；
- 用户态 Page Fault；
- `kill 4`；
- 同步 `user` 命令返回。

### 2. 用户页表骨架

初始化时创建一张可复用的用户页表并保留。代码、数据和栈页会动态回收，页表本身作为
用户地址空间基础设施长期存在，避免每次进程启动重复创建页表。

### 3. 失败回滚

如果三页中的任一分配或映射失败，初始化路径会释放此前已经成功分配的页面，避免部分
创建导致物理页泄漏。

### 4. 账目验证

实测：

```text
运行前  Memory Map used=35/32480
运行中  Memory Map used=38/32480
退出后  Memory Map used=35/32480
```

运行期间增加的三页正好对应 code/data/stack，退出后全部恢复。

### 5. 自动测试

```bash
make test-resources
```

测试自动比较三次 `memmap`：

- 运行中使用页数必须等于基线加 3；
- 退出后使用页数必须与基线完全一致。

成功输出：

```text
OrangeOS user page resource reclamation test passed
```
