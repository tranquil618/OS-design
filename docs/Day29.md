# OrangeOS Day29 开发日志

## 今日目标

将 ORF6 的“损坏后重建”升级为 ORF7 双目录副本恢复。

## 磁盘布局

```text
LBA 42       primary directory
LBA 43-74    32 data sectors
LBA 75       backup directory
```

两份目录均包含 `ORF7` 魔数、分配位图、7 个目录项、32 位版本号和 XOR 校验。

## 提交顺序

目录发生变化时：

1. 版本号递增；
2. 重新计算目录校验；
3. 写入 LBA 75 备份目录；
4. 写入 LBA 42 主目录。

如果系统在两次写入之间中断，备份目录拥有更新版本。下次启动会选择版本更新且
校验有效的副本，并把它同步回另一位置。

## 启动选择规则

- 两份都无效：格式化为默认 ORF7；
- 只有一份有效：用有效副本修复另一份；
- 两份都有效：选择版本号较大的副本；
- 两份版本相同：使用主目录并同步备份。

## 故障注入验证

```bash
make test-fs-checksum
```

测试会建立 `keep` 文件并写入 `survives`，随后直接破坏主目录位图字节。重新启动
后验证：

```text
survives
OrangeFS free=24/32 sectors
```

这证明系统从备份目录恢复了用户文件，而不是回退到默认格式化。
