# OrangeOS Day30 开发日志

## 今日目标

在 ORF7 双目录保护的基础上，为文件数据增加完整性检测，形成 ORF8。

## 数据校验

每个 24 字节目录项的最后两个字节保存文件有效内容的 16 位加法校验值。校验只
覆盖 `size` 指定的字节，不包含扇区尾部填充。

校验值会在以下场景生成：

- 创建默认文件系统；
- `write <file> <text>` 成功写入数据后。

以下读取路径会验证数据：

- `cat <file>`；
- `exec <file>`，因为 OEX 加载复用文件读取接口。

校验失败时 Shell 显示：

```text
File data corrupt
```

## 答辩意义

现在文件系统已经形成两层完整性保护：目录元数据由双副本、版本号和 XOR 校验
保护；文件内容由目录项内的数据校验保护。演示时可以直观展示“篡改磁盘后系统
拒绝错误数据”和“主目录损坏后恢复用户文件”两条可靠性路径。
