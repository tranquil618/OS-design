# OrangeOS Day6 开发日志

## 终端输入区域限制与命令提示符

## 一、今日开发目标

今天主要完善 OrangeOS 的终端输入体验：

1. 增加 `OrangeOS>` 命令提示符；
2. 保存当前光标位置；
3. 记录用户输入区域的起始位置；
4. 限制退格操作，防止删除提示符和之前的屏幕内容；
5. 为后续实现 Shell 命令输入打基础。

## 二、增加命令提示符

Kernel 启动并输出：

```text
OrangeOS Kernel Started!
```

随后换行并显示：

```text
OrangeOS>
```

提示符由 Kernel 中的字符串定义：

```asm
prompt:
    db 'OrangeOS>',0
```

显示提示符后，用户可以在其后方输入字符，使系统界面开始具备命令行终端的基本形式。

## 三、记录当前光标位置

为了让字符串输出、字符输入、换行和退格使用同一个位置，增加了：

```asm
cursor_pos:
    dw 0
```

`print_string` 和 `print_color_string` 输出完成后，会把新的显存偏移保存到 `cursor_pos`。

单个字符输出时，`put_char` 从 `cursor_pos` 读取当前位置，写入字符和颜色后，再更新光标位置。

## 四、设置用户输入区域

显示 `OrangeOS>` 后，Kernel 读取当前光标位置，并调用：

```asm
set_terminal_start
```

该函数将当前位置同时保存到：

```asm
terminal_start
cursor_pos
```

其中：

- `cursor_pos` 表示当前字符输出位置；
- `terminal_start` 表示本次用户输入允许到达的最前位置。

这样可以明确区分提示符区域和用户输入区域。

## 五、增加退格区域限制

退格处理前，系统会比较：

```asm
cursor_pos
terminal_start
```

如果两个位置相同，说明光标已经到达用户输入区域的起点，此时退格不再继续执行。

核心判断：

```asm
cmp bx,[terminal_start]
je backspace_done
```

只有光标位于输入区域起点之后时，才会：

1. 将显存位置向前移动一个字符；
2. 使用空格覆盖原字符；
3. 恢复默认颜色；
4. 保存新的光标位置。

最终实现的效果是：用户可以删除自己输入的字符，但不能继续向前删除 `OrangeOS>` 提示符。

## 六、键盘输入流程

当前键盘循环为：

```text
读取键盘字符
      ↓
写入输入缓冲区
      ↓
在当前光标位置显示
      ↓
继续等待键盘输入
```

普通字符、回车和退格分别由输入缓冲区与字符显示模块处理。
